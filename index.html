📖 Petunjuk Penggunaan Game

  1. Pilih satu dari 3 game di menu. Setiap game mengajarkan satu konsep berpikir komputasional.
  2. Baca kotak Cara Bermain, pilih level, lalu tekan Main.
  3. Raih sampai 3 bintang ⭐ di setiap level. Bintang tertinggi tersimpan selama halaman terbuka.
  4. Tombol 🎵 = musik, 🔊 = efek suara, ⛶ = layar penuh (cocok untuk PID). Klik judul 🎮 untuk kembali ke menu.
  5. Bermain berkelompok? Gantian satu orang memegang mouse, yang lain ikut memberi strategi.
